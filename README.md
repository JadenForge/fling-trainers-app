# 风灵月影修改器合集（桌面客户端）

一个跨平台（**macOS + Windows**）的修改器合集客户端，界面参考风灵月影官方合集 App：
顶部四个页签（全部修改器 / 我的收藏 / 我的下载 / 设置）、搜索框、排序胶囊、封面卡片网格，
每张卡片提供 **运行 / 下载 / 收藏 / 删除** 操作。

数据与封面全部来自风灵月影官网 `flingtrainer.com`，中文名取自其官方中文论坛帖标题，
**可以在应用内一键从主站刷新保持最新**。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 全部修改器 | 展示主站全量修改器（默认 750+ 条），卡片显示封面、中文名、修改项数量与更新时间 |
| 分页 | 每页 72 条，底部提供「上一页 / 页码 / 下一页 / 跳至第 N 页」；滤波切换自动回到第 1 页 |
| 搜索 | 支持中文名 / 英文名实时筛选，`⌘/Ctrl + F` 聚焦搜索框 |
| 排序 | 最近更新 / 最新发布 / 最近使用，另有一键「刷新列表」 |
| 我的收藏 | 收藏的修改器集中展示，带数量角标 |
| 我的下载 | 已下载的修改器集中管理，可运行、打开所在目录、删除 |
| 运行 | 在「本地修改器目录」里按游戏名模糊匹配可执行文件并启动；找不到时可手动指定 |
| 下载 | 直连官网真实下载地址（自动带 Referer），实时显示进度与速度 |
| 删除 | 已下载 → 删除本地文件；未下载 → 从列表移除（可在设置中恢复） |
| 设置 | 修改器目录、下载目录、卡片尺寸、封面本地缓存、显示已移除条目、数据刷新、重置 |
| 详情抽屉 | 点击封面查看中英文名、支持版本、修改项完整列表、历史下载文件（可挑选版本下载） |

## 目录结构

```
fling-trainers-app/
├── package.json
├── data/
│   └── trainers.json        # 抓取生成的修改器数据（含中文名 / 封面 / 版本 / 下载地址）

    ├── main.js              # 主进程：窗口、存储、下载、运行、刷新
    ├── preload.cjs          # 安全桥接（contextBridge）
    └── renderer/
        ├── index.html
        ├── styles.css
        └── app.js
```

## 开发运行

### 最简单：双击启动

在 Finder 里双击项目根目录的 **`启动应用.command`**，会自动打开终端并拉起应用。

### 命令行

```bash
cd fling-trainers-app
npm install          # 首次安装 Electron，约 300MB
npm run build:data   # 抓取一次数据（生成 data/trainers.json）
npm start            # 启动应用
npm run dev          # 启动并打开开发者工具
```

### 在受限环境（沙箱 / 无 GPU）里启动

有些沙箱会注入 `ELECTRON_RUN_AS_NODE`、`NODE_OPTIONS`，并禁用 Chromium 沙箱与 GPU，
直接 `npm start` 会起不来。用附带的脚本即可（会自动清理环境变量并按需补参数）：

```bash
bash scripts/run-local.sh
```

> ⚠️ 不要用 `osascript ... activate` 或 `open -b com.github.Electron` 去“唤到前台”，
> 这两条在本机都会**再启动一个空的 Electron 窗口**（显示 "To run a local app…"）。
> 想把窗口切到前台，请用 `Cmd + Tab` 或点 Dock 上的 Electron 图标。

### 自检模式

```bash
bash scripts/run-local.sh --smoke      # 页面自检 + 4 张截图，约 15 秒后自动退出
bash scripts/run-local.sh --verify     # 分页交互用例回归（35 项断言），约 60 秒后退出
bash scripts/run-local.sh --soak       # 翻页压力自检：每 3 秒翻一页，30 轮后退出
```

**`--smoke`** 会截图到 `build/`：

| 文件 | 内容 |
| --- | --- |
| `smoke.png` | 第 1 页顶部 |
| `smoke-page2.png` | 翻到第 2 页 |
| `smoke-pager.png` | 滚到页面底部的分页条 |
| `smoke-pager-narrow.png` | 窄窗口下的分页条（检查是否破版） |
| `smoke-detail.png` | 详情抽屉 |

**`--verify`** 会驱动真实 UI 跑 35 项断言，覆盖：页码窗口（首页 / 中间页 / 末页）、
`gotoPage` 越界与 NaN 夹取、跳转框输入 99 / 0 / 非数字、翻页后滚动复位、
搜索/排序/Tab 切换重置页码、搜索结果缩小后的页码 clamp、空态、收藏增删与角标、
连续快速翻页（防吞点击）、**删除最后一条后页码从第 2 页 clamp 回第 1 页**、窗口尺寸变化。

报告写到 `build/verify-report.json`，控制台输出 `VERIFY_DONE {total,passed,failed}` 与逐条 `VERIFY_FAIL`，
同时每条结果都会记进 `app.log`。

> ⚠️ `--verify` 里有一项会**真实删除一条修改器记录**（用于验证页码 clamp），跑完请在
> 「设置 → 显示已删除的条目」里恢复，或先备份 `state.json`。

**`--soak`** 会反复点「下一页」直到末页再跳回第 1 页，记录每轮的卡片数、页码、
JS 堆内存与内容高度。正常表现：页码严格递进，峰值堆内存恒定在 ~10MB。

## 打包发布

```bash
npm run dist:mac     # 产出 dmg / zip（x64 + arm64）
npm run dist:win     # 产出 nsis 安装包 / 免安装 portable（x64）
```

产物在 `release/` 目录。跨平台打包建议在对应系统上执行（Windows 包在 macOS 上需要 Wine）。

## 数据刷新机制

应用启动时会读取 `data/trainers.json`。点击「刷新列表」或在设置页刷新时，主进程会调用
`scripts/build-data.mjs`：

1. 抓取 `https://flingtrainer.com/all-trainers/` 获取全量修改器清单（英文名 + 链接）
2. 抓取中文论坛 `修改器发布区` 全部页，解析《中文名（English Name）》得到**官方中文名**
3. 逐条抓取详情页，解析封面图（`og:image`）、支持版本、最后更新、修改项列表、历史下载文件
4. 写入可写目录：`<用户数据目录>/trainers.json`（打包后不会写入只读的 app.asar）

- **增量更新**：已抓过的条目跳过详情页，只补新增条目，速度快
- **完整刷新**：重新抓取全部详情页，适合数据异常时使用

数据里没能自动匹配到中文名的条目，脚本内置了一份人工校对表（键为归一化英文名），
新增游戏只要出现在中文论坛帖里就会自动匹配。

## 运行按钮的工作原理

修改器本体是官网分发的 Windows 可执行文件，客户端不内置、不分发。点击「运行」时：

1. 若该游戏已在「我的下载」中，优先启动下载得到的文件
2. 否则在「设置 → 本地修改器目录」中**递归查找**文件名与游戏（中文名/英文名）匹配的程序
   （`.exe` / `.app` / `.command` / `.sh`），命中即启动
3. 都找不到时，弹出对话框让你手动指定要启动的程序

> macOS 上如果要用 Windows 版修改器，需要自行安装 Wine 等兼容层；
> 在 macOS 原生可用的场景下请选择 `.app` 形式的程序。
